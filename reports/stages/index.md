# Stage Report Routing

This file is a routing tombstone, not the current report dashboard.

Use [`ARTIFACT_INDEX.md`](../../ARTIFACT_INDEX.md) for current artifact
ownership, active context, optional evaluation tracks, historical material, and
ignored runtime outputs.

The former `reports/stages/index.json` manifest was historical PHAK-era
metadata and is now in the dated external research archive. It is not current
system truth and is not recreated by the runtime.

Current ingestion-first evaluation evidence is retained here only when it is
listed as current in `ARTIFACT_INDEX.md`. Superseded reports are preserved in
the external archive described by
[`docs/repository_artifact_policy.md`](../../docs/repository_artifact_policy.md).
Detailed provider responses and parsed trial artifacts remain ignored local
material.
