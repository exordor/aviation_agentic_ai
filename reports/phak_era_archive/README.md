# PHAK-Era Archived Final Report Artifacts

This directory holds final-report and defense-deck artifacts from the project's
earlier aviation-training (PHAK Chapter 4) route. They are preserved for
provenance, but the CLI commands that generated them have been retired.

The active thesis line is:

> Agentic KG-RAG for evidence-grounded question answering over retrospective
> FAA ATCSCC advisories.

For current final-report material, see `reports/final/atcscc_*.md` instead.

## Why these files were archived

These files were generated by four CLI commands (`aviation-ai report project`,
`academic-paper`, `defense-notes`, `defense-deck-outline`) that produced
PHAK-era report drafts. The commands and their writer functions were removed
in favor of the current ATCSCC thesis report (`atcscc_thesis_report.md`) and
defense deck outline (`atcscc_defense_deck_outline.md`).

These files may be consulted for historical context (how the report evolved
from PHAK to ATCSCC). They must not be loaded as current thesis story.
